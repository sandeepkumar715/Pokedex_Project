# Pokedex Project

A React-based Pokedex application that fetches Pokemon data from the PokeAPI.

## Features

- Display Pokemon list
- Pokemon images
- Pokemon names
- Pokemon types
- Data fetched using Axios
- Loading state while fetching data
- Built with React and Vite

## Tech Stack

- React.js
- JavaScript
- Axios
- CSS
- Vite
- PokeAPI

## API

This project uses [PokeAPI](https://pokeapi.co/) to fetch Pokemon data.
